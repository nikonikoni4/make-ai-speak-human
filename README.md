# 让 AI 说人话

一份中文输出风格规则，用来约束 AI 的回答方式。它服务的目标读者是「需要看懂 AI 回答的人」。

## 一、它是什么

`output-style-zh.md` 是一份提示词。把它附加到提问后面，AI 就会按指定风格组织回答。

规则分两组，共 14 条。

**句子层（11 条，编号 0–10）** 管一句话怎么写：

| 条目 | 要求 |
|---|---|
| 0 | 主语、谓语、宾语必须齐全 |
| 1 | 单句控制在 20 字以内，40 字以上不接受 |
| 2 | 用简单句和并列句，少用复合句 |
| 3 | 用肯定句表达 |
| 4 | 不用双重否定 |
| 5 | 用主动语态 |
| 6 | 用现代汉语常用词 |
| 7 | 代词指代明确，只有一个含义 |
| 8 | 名词前少堆形容词 |
| 9 | 不用装饰性比喻 |
| 10 | 不在给出答案前先否定 |

**观点层（3 条）** 管一段话怎么组织：

| 条目 | 要求 |
|---|---|
| 1 | 总分表达，先给结论再分点 |
| 2 | 前提必须声明 |
| 3 | 关键词必须声明 |

## 二、目的

让 AI 说的话更容易被人理解。

AI 默认的输出方式会设置六道门槛。

**第一道，句子太长。**（句子 1）
读者要在一句话里同时记住好几件事。读到后半句，前半句已经忘了。

**第二道，句式太复杂。**（句子 2）
复合句套着复合句。读者要先拆解句子结构，才能拿到信息。

**第三道，主语或宾语缺失。**（句子 0）
读者不知道「谁对谁做了什么」。

AI 解释 numpy 广播机制时，给出过这样一句定义：

> 右对齐：从最后一个维度往前比，短的那个在左边补

这句话缺了四个成分。谁和谁比？「短的」指什么？补什么？补在哪里？读者读完拿不到一个可以照着做的动作。

**第四道，概念太多。**（观点 3）
读者遇到不认识的术语，只能跳过，或者停下来猜。两种情况都会打断阅读。

**第五道，无用的比喻。**（句子 9）
比喻让读者多处理一层意象，却没有带来新信息。读者要先把比喻翻译回原意，才能继续读。

**第六道，否定式表达。**（句子 10）
读者要先解析「不是什么」，才能理解「是什么」。如果被否定的东西他本来就没想过，这一步白读。

规则针对这六点：拆短句子，简化句式，补齐成分，就地解释术语，删掉比喻，直接给答案。

## 三、副作用

**内容可能不够深入。**

规则第 2 条要求「避免一次性输出内容过长」。AI 会主动压缩篇幅，压缩掉的通常是机制原理、边界情况、实现细节。

这个取舍在两类场景下合适：

- 读者是初学者，需要先建立主干认知，细节留到后面补。
- 读者对该领域不熟悉，深入内容会增加理解负担，反而挡住主干。

在另外两类场景下需要警惕：

- 读者要照着实现，需要精确细节。
- 读者在排查疑难问题，需要边界情况。

规则本身不禁止深入。它要求先讲清主干，再谈细节。读者需要细节时，追问一次即可。

## 六、已知局限

- 规则没有区分「解释」和「简述」。用户要求详细解释时，AI 仍可能按「避免过长」压缩篇幅。
